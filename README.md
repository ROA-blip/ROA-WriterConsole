# ROA Writer's Console

An interactive Story Bible and Writer's Console for the novel series **Rise of the Awares (ROA)**.

## Purpose

The Writer's Console is the canonical reference for the ROA universe. It is designed to help maintain continuity, track story development, and support collaboration throughout the writing process.

### Features

- Character Profiles
- Timeline
- Locations
- Technologies
- Organizations
- Relationships
- Themes
- Knowledge Matrix
- Continuity Tracking
- Decision Log
- Search
